## README 작성 원칙

- 루트 README는 "같은 작업 절차를 다시 따라할 수 있는 참고서"처럼 쓴다.
- 코드베이스의 현재 상태를 기준으로 적는다.
- 아직 미완성인 부분이 있으면 숨기지 말고 현재 상태 그대로 적는다.
- 실행 명령, 의존성, 파일 역할, 포트/호스트 같은 재현 핵심 정보는 반드시 포함한다.
- 단순 파일 나열이 아니라 실제 따라 할 수 있는 순서로 정리한다.

## diff 기준

아래 항목은 README와 실제 상태를 반드시 대조한다.

- 새로 생긴 실행 파일이 있는가
- 실행 진입점이 바뀌었는가
- `uv add`로 들어간 의존성이 README에 빠졌는가
- 포트, 호스트, `reload` 설정이 바뀌었는가
- 테스트/검증용 스크립트가 추가됐는가
- README가 더 이상 맞지 않는 예전 설명을 유지하고 있는가
- 실제 실행에 필요한 선행 파일이 비어 있거나 누락되어 있는가
